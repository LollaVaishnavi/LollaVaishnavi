forecast-cost-audit

Impossibility: Aggregation

Asymmetric newsvendor cost auditing and exact Cost-SHAP for demand forecasting

Structural Impossibility: A symmetric forecast error metric (MAPE or RMSE) collapses under-forecasting and over-forecasting into one scalar, so it cannot tell whether a lower-error model increases stockout and holding cost.
  • MSE achieves 23.2% lower RMSE yet incurs 41.5% higher inventory cost ($17,899.24 extra) at 5:1 asymmetry
  • Fixed portfolio q=0.833 loses at 3 of 9 cost ratios (46.3% more than MSE at 1:1) and loses +9.0% on 7 of 12 low-margin staples
  • Exact 32-coalition Cost-SHAP shows 3 feature groups save real stockout dollars while hurting symmetric RMSE

prompt-eval-power

Impossibility: Resolution

Statistical regression gate and power analyzer for RAG and LangGraph prompt suites

Structural Impossibility: A pass-rate threshold on a small prompt evaluation set cannot separate a real prompt regression from binomial sampling noise, so a CI gate either ships broken prompts or blocks harmless edits.
  • A 30-query prompt suite has a 75.2% false-pass rate on a 10pp drop and a 28.7pp MDE at 80% power
  • 0/30 failures still leaves a 9.5% true failure upper bound (95% Clopper-Pearson); <1% requires 299 zero-failure queries
  • On 300 labeled queries, n=30 exits 3 (UNDERPOWERED, deficit of 216 queries) where n=300 catches 29 pass-to-fail flips

late-event-feature-audit

Impossibility: Missing Edge

Bitemporal point-in-time leakage replay across Kafka, Spark Streaming, S3, GCS, and Azure

Structural Impossibility: A batch warehouse query over current table state has no edge recording when late-arriving streaming events actually landed, so offline training features silently leak future information that online serving never had at prediction time.
  • 2-hour p95 arrival lag corrupts 7.4% of training rows and inflates offline ROC-AUC by 4.7 points (8.4 points at 12h lag)
  • A tight 15-minute Spark Streaming watermark drops 59.4% of late events (804 of 1353 evicted)
  • Unified manifest adapter proves byte-identical SHA-256 parity across 3 cloud providers (s3://, gs://, az://)

delayed-label-drift-gate

Impossibility: Irreversibility

Irreversible escaped-decision exposure monitoring with PSI, KS, SHAP-shift, FastAPI, Docker, and MLflow

Structural Impossibility: Predictions served before ground-truth labels arrive cannot be recalled, so a production monitor can only bound how many bad decisions escape during the label-delay window, never prevent them retroactively.
  • Waiting 30 days for labels leaks 2614 escaped bad decisions ($65,350); even day +3 SHAP-shift lets 280 bad decisions escape
  • Under pure concept drift (stationary P(X)), PSI, KS, and SHAP-shift miss all 6995 bad decisions ($174,875)
  • Noise-only drift triggers a 100.0% false-alarm rate on PSI and KS; exact SHAP-shift attributes 56.1% of drift to order_velocity
